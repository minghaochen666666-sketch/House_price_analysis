Overview
This project briefly analyzes 4600 housing data points in the Washington State housing market across 44 cities and 77 zip codes to identify some factors that influence prices and unit prices (price per sqft). Exploring market trends, evaluating factors through SQL-based analysis, Python matplotlib visualizations and a Google Sheet dashboard.
This project combines:
MySQL for data querying and aggregation
Python (Pandas, Matplotlib) for formatting and visualization
Google Sheets for KPI and dashboard report
Dataset
The dataset was obtained from the open Kaggle House Prices dataset and contains information on houses, including information such as:
Price
Bedrooms
Sqft_living
Floors
Waterfront
View
Condition
The dataset had already undergone cleaning and preprocessing. Data validation checks were performed to ensure it's ready for Exploratory data analysis.
Project Objectives
The analysis aims to answer the following questions:
What is the overall distribution of house prices?
How does living area affect sale price?
How does bedroom count impact property value?
Do waterfront properties sell at a higher price?
Which other criteria impact housing prices?

Key Findings
House prices are concentrated in the low-mid market.
Living area strongly influences housing prices
Bedroom count affects the value
Houses that have a better view generally have a larger unit price(price per square foot)
Houses that have more floors overall have a larger unit price
Houses that have the waterfront have larger total price, unit price as well as bigger in scale
All these conclusions are correlations based on the database instead of causations
